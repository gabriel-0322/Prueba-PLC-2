Esquemático Digital de Compuertas Lógicas y Ecuaciones Booleanas

Traducción directa de la lógica combinacional y secuencial del PLC a compuertas normalizadas IEEE/IEC. Las líneas cambian de color en tiempo real (Verde = Nivel Alto 1, Gris = Nivel Bajo 0) según la simulación en vivo.

Origen de Señales:
Enclavamiento del Sistema (M0.0)
M0.0 = (I0.0 + M0.0) · NOT(I0.1) · I0.2 · I0.3 · I0.4 · I0.6 · NOT(M0.4)
El sistema solo arranca si hay bidón (I0.2), tanques OK (I0.3, I0.4), sin E-Stop (I0.6) y sin bloqueo Poka-Yoke previo.
Electroválvula Base Agua (Q0.0)
Q0.0 = M0.0 · NOT(T1.DN)
Se energiza durante los primeros 4.0 segundos mientras el temporizador T1 no haya alcanzado el tiempo preestablecido (PT).
Electroválvula Concentrado (Q0.1)
Q0.1 = M0.0 · T1.DN · [(NOT(I0.5) · NOT(T2.DN)) + (I0.5 · NOT(T3.DN))]
Inicia al finalizar T1. Si I0.5=0 dosifica 2.0s (T2); si I0.5=1 dosifica 5.0s (T3).
Motor Agitador Mezclador (Q0.2)
Q0.2 = M0.0 · [(NOT(I0.5) · T2.DN) + (I0.5 · T3.DN)] · NOT(T4.DN)
Homogeneiza el fluido tras finalizar el concentrado durante 3.0s (Hogar) o 4.0s (Industrial).
Luz Verde y Memoria Poka-Yoke (Q0.3 & M0.4)
M0.4(SET) = T4.DN · I0.2  |  M0.4(RESET) = NOT(I0.2)
Q0.3 = M0.4 · I0.2
Al terminar T4, M0.4 se enclava bloqueando nuevos ciclos. Q0.3 brilla avisando al operario para retirar el bidón. M0.4 solo se libera cuando el bidón es retirado (I0.2 pasa a 0).
Baliza Roja de Alarma (Q0.4)
Q0.4 = NOT(I0.3) + NOT(I0.4) + NOT(I0.6)
Activa alarma visual si cualquier tanque baja del 15% o si se oprime el paro de emergencia.

Memoria Técnica y Arquitectura de Automatización Industrial

Especificación formal de ingeniería para la modernización de planta: control discreto secuencial, análisis de mermas y mapa de memoria del PLC.

SECCIÓN 1

1. Diagnóstico del Problema y Justificación Económica

La operación histórica de dosificación a granel se realizaba mediante manipulación manual con válvulas de mariposa de accionamiento manual y jarras plásticas graduadas. Este método generaba cuatro problemas críticos:

  • Merma sistemática de materia prima (14.2% promedio): Sobrellenado por error de paralaje del operario y goteo constante al trasvasar concentrados activos.
  • Inconsistencia química en diluciones: Variabilidad en la concentración de tensioactivos biodegradables y bactericidas de hasta ±22%, provocando reclamos por falta de viscosidad o formación excesiva de espuma.
  • Riesgo ergonómico y de seguridad ocupacional: Salpicaduras accidentales de productos alcalinos/ácidos sobre el personal y fatiga por carga repetitiva de garrafas de 20 litros.
  • Pérdida de trazabilidad de inventario: Descuadre entre los insumos químicos descargados en bodega y las unidades comercializadas al finalizar el turno.
-98.5% Mermas por derrames
< 0.5% Tolerancia de mezcla
100% Trazabilidad por lote
SECCIÓN 2

2. Alcance Técnico y Filosofía de Control

El proyecto implementa una celda de manufactura discreta con controlador lógico programable (PLC) bajo estándar IEC 61131-3:

  • Control secuencial determinístico: Ejecución cronometrada por bloques de temporización al retardo a la conexión (TON) con base de tiempo en milisegundos.
  • Protección de marcha en seco y enclavamiento por nivel: Monitoreo continuo de boyas de nivel capacitivas industriales (I0.3 e I0.4) para evitar cavitación o diluciones incompletas.
  • Lógica Poka-Yoke (A prueba de errores): Mecanismo de enclavamiento por software que inhabilita cualquier nuevo pulso de arranque (I0.0) hasta que el operario retire físicamente el envase finalizado de la base receptora.
  • Flexibilidad multirreceta: Selector físico de 2 posiciones para conmutar entre producto para consumo doméstico (baja viscosidad) y producto industrial de alta densidad de tensoactivo.

SECCIÓN 4

4. Descripción del Ciclo Scan y Mecanismo Poka-Yoke Anti-Doble Llenado

1

Lectura del Mapeo de Entradas (PII)

La CPU actualiza la imagen de proceso de entradas (I0.0 a I0.7) en un instante t0, aplicando filtro antirrebote de hardware (3ms).

2

Ejecución Determinística de la Lógica (Ladder Rungs)

Se evalúan secuencialmente los 7 escalones de izquierda a derecha y de arriba a abajo. Se calculan los temporizadores TON y memorias M0.0 y M0.4.

3

Escritura en Imagen de Salidas (PIQ)

Las salidas físicas Q0.0 a Q0.4 se actualizan sincrónicamente al terminar el escaneo, garantizando que no existan estados transitorios espurios en las válvulas.

¿Cómo Garantiza el PLC que no ocurra un Doble Llenado por Error Humano?

En una estación manual convencional, si un operario distraído vuelve a presionar el pedal o botón de inicio mientras el bidón lleno continúa en la base, el líquido rebosa, derramando producto químico costoso e irritante.

En CleanDose PLC, la lógica implementa el bit auxiliar M0.4 (Poka-Yoke Lock):

// Cuando finaliza la etapa de mezcla (T4.DN = 1) y el bidón sigue presente (I0.2 = 1): SET(M0.4); // En el escalón de arranque (Network 1): M0.0 = (I0.0 + M0.0) · ... · NOT(M0.4); // -> Como M0.4 = 1, NOT(M0.4) = 0, haciendo IMPOSIBLE energizar M0.0 aunque se pulse I0.0 repetidamente. // El único evento capaz de resetear M0.4 es la transición a cero de I0.2: IF (I0.2 == 0) THEN RESET(M0.4);

Este diseño cumple con el principio de ingeniería Poka-Yoke: la máquina no confía en la atención del operador; la física del sensor gobierna el permiso de rearme.

Manual de Demostración y Guía de Migración a Proteus VSM

Protocolo de operación para pruebas de laboratorio y guía de diseño circuital para simular esta estación en Proteus con microcontroladores PIC/Arduino o lógica digital cableada.

MANUAL RÁPIDO

Protocolo de Demostración en Vivo (Paso a Paso)

  1. Verificación de Tanques (I0.3 e I0.4): Asegúrese de que ambos tanques tengan > 15% de nivel. Los LEDs I0.3 e I0.4 en el rack del PLC deben estar encendidos en verde.
  2. Prueba de Enclavamiento Preventivo (Sin Bidón): Pulse el botón verde START (I0.0) sin colocar el bidón. Observe que el sistema NO arranca debido al contacto abierto I0.2 en Network 1.
  3. Inserción de Envase: Haga clic en "Colocar Bidón Vacío" en la Zona A. El sensor óptico I0.2 se activará con haz láser verde.
  4. Selección de Receta: Gire la perilla de receta a Fórmula Hogar (4s base, 2s concentrado) o Fórmula Industrial (4s base, 5s concentrado).
  5. Inicio de Dosificación: Pulse START (I0.0). Se activará EV1 (Q0.0), luego EV2 (Q0.1), y finalmente el motor agitador MTR1 (Q0.2). Observe la fluidez de las tuberías y el llenado progresivo.
  6. Comprobación Poka-Yoke: Con el bidón ya lleno y la luz verde (Q0.3) encendida, vuelva a presionar START. ¡El sistema rechazará el ciclo! Solo tras pulsar "Retirar Bidón Lleno" el sistema quedará disponible para el siguiente ciclo.
  7. Prueba de Fallas Críticas: Durante la dosificación, pulse el hongo de PARO DE EMERGENCIA (I0.6) o haga clic en "Vaciar T1 (<15%)": todas las salidas se desenergizarán en menos de 50 ms y se activará la baliza roja (Q0.4).

Código C++ Listo para Compilar y Cargar en Proteus VSM

Estructura FSM no bloqueante con emulación de ciclo scan de PLC de 50ms 
// =====================================================================
// CleanDose PLC - Firmware de Emulación para Proteus VSM (Arduino Uno)
// Arquitectura: Máquina de Estados Finita (FSM) no bloqueante
// =====================================================================

// --- ASIGNACIÓN DE PINES ---
const int PIN_START     = 2;   // I0.0 (NA)
const int PIN_STOP      = 3;   // I0.1 (NC)
const int PIN_BIDON     = 4;   // I0.2 (Sensor óptico)
const int PIN_NVL_T1    = 5;   // I0.3 (Boya T1 > 15%)
const int PIN_NVL_T2    = 6;   // I0.4 (Boya T2 > 15%)
const int PIN_RECETA    = 7;   // I0.5 (0 = Hogar, 1 = Industrial)
const int PIN_ESTOP     = 8;   // I0.6 (NC de seguridad)
const int PIN_RESET     = 9;   // I0.7 (Reset alarmas)

const int PIN_EV1_BASE  = 10;  // Q0.0 (Válvula Base Agua)
const int PIN_EV2_CONC  = 11;  // Q0.1 (Válvula Concentrado)
const int PIN_MOTOR     = 12;  // Q0.2 (Motor Mezclador)
const int PIN_LED_OK    = A0;  // Q0.3 (Piloto Verde Listo)
const int PIN_LED_ALARM = A1;  // Q0.4 (Baliza Roja Alarma)

// --- ESTADOS DE LA MÁQUINA SECUENCIAL ---
enum EstadoPLC {
  IDLE,              // Esperando bidón y start
  DOSIFICANDO_BASE,  // EV1 activa (4.0s)
  DOSIFICANDO_CONC,  // EV2 activa (2.0s o 5.0s)
  HOMOGENEIZANDO,    // Motor activo (3.0s o 4.0s)
  CICLO_COMPLETO,    // Luz Verde y bloqueo Poka-Yoke activo
  ALARMA_BLOQUEO     // Paro de emergencia o tanques vacíos
};

EstadoPLC estadoActual = IDLE;

// --- VARIABLES Y BANDERAS INTERNAS ---
unsigned long tiempoInicioEtapa = 0;
bool m0_4_poka_yoke_lock = false;
unsigned int contadorBidones = 0;

void setup() {
  // Configuración de Entradas con Pull-Up o Pull-Down
  pinMode(PIN_START, INPUT);
  pinMode(PIN_STOP, INPUT_PULLUP);
  pinMode(PIN_BIDON, INPUT);
  pinMode(PIN_NVL_T1, INPUT);
  pinMode(PIN_NVL_T2, INPUT);
  pinMode(PIN_RECETA, INPUT);
  pinMode(PIN_ESTOP, INPUT_PULLUP);
  pinMode(PIN_RESET, INPUT);

  // Configuración de Salidas a Relé / Driver
  pinMode(PIN_EV1_BASE, OUTPUT);
  pinMode(PIN_EV2_CONC, OUTPUT);
  pinMode(PIN_MOTOR, OUTPUT);
  pinMode(PIN_LED_OK, OUTPUT);
  pinMode(PIN_LED_ALARM, OUTPUT);

  apagarTodasSalidas();
  Serial.begin(9600);
  Serial.println("CleanDose PLC Inicializado - Scan 50ms deterministico");
}

void loop() {
  unsigned long tActual = millis();

  // 1. LECTURA DE IMAGEN DE ENTRADAS (PII)
  bool inStart  = digitalRead(PIN_START) == HIGH;
  bool inStop   = digitalRead(PIN_STOP) == HIGH; // NC: HIGH es normal
  bool inBidon  = digitalRead(PIN_BIDON) == HIGH;
  bool inNvlT1  = digitalRead(PIN_NVL_T1) == HIGH;
  bool inNvlT2  = digitalRead(PIN_NVL_T2) == HIGH;
  bool inReceta = digitalRead(PIN_RECETA) == HIGH; // 0: Hogar, 1: Ind
  bool inEStop  = digitalRead(PIN_ESTOP) == HIGH;  // NC: HIGH es seguro
  bool inReset  = digitalRead(PIN_RESET) == HIGH;

  // 2. GESTIÓN DE SEGURIDAD PRIORITARIA (PARO Y BAJO NIVEL)
  if (!inEStop || !inNvlT1 || !inNvlT2 || !inStop) {
    estadoActual = ALARMA_BLOQUEO;
  }

  // Desbloqueo Poka-Yoke cuando se retira el bidón (I0.2 pasa a LOW)
  if (!inBidon) {
    m0_4_poka_yoke_lock = false;
  }

  // Reset de contador y rearme
  if (inReset) {
    contadorBidones = 0;
    if (inEStop && inNvlT1 && inNvlT2) {
      estadoActual = IDLE;
    }
  }

  // 3. EJECUCIÓN DE LA MÁQUINA DE ESTADOS (LADDER EQUIVALENTE)
  switch (estadoActual) {
    case IDLE:
      apagarTodasSalidas();
      // Condición de arranque: Bidón presente + Start pulsado + Permisivos OK + Sin Bloqueo Poka-Yoke
      if (inStart && inBidon && inNvlT1 && inNvlT2 && !m0_4_poka_yoke_lock) {
        tiempoInicioEtapa = tActual;
        estadoActual = DOSIFICANDO_BASE;
      }
      break;

    case DOSIFICANDO_BASE:
      digitalWrite(PIN_EV1_BASE, HIGH); // Q0.0 ON
      digitalWrite(PIN_EV2_CONC, LOW);
      digitalWrite(PIN_MOTOR, LOW);
      digitalWrite(PIN_LED_OK, LOW);
      digitalWrite(PIN_LED_ALARM, LOW);

      // TON T1 = 4.0 segundos
      if (tActual - tiempoInicioEtapa >= 4000) {
        digitalWrite(PIN_EV1_BASE, LOW);
        tiempoInicioEtapa = tActual;
        estadoActual = DOSIFICANDO_CONC;
      }
      break;

    case DOSIFICANDO_CONC:
      digitalWrite(PIN_EV2_CONC, HIGH); // Q0.1 ON
      
      // Selección de tiempo según receta (I0.5): Hogar = 2.0s, Industrial = 5.0s
      unsigned long tiempoConc = inReceta ? 5000 : 2000;
      if (tActual - tiempoInicioEtapa >= tiempoConc) {
        digitalWrite(PIN_EV2_CONC, LOW);
        tiempoInicioEtapa = tActual;
        estadoActual = HOMOGENEIZANDO;
      }
      break;

    case HOMOGENEIZANDO:
      digitalWrite(PIN_MOTOR, HIGH); // Q0.2 ON
      
      // TON T4 = 3.0s (Hogar) o 4.0s (Industrial)
      unsigned long tiempoMezcla = inReceta ? 4000 : 3000;
      if (tActual - tiempoInicioEtapa >= tiempoMezcla) {
        digitalWrite(PIN_MOTOR, LOW);
        contadorBidones++;
        m0_4_poka_yoke_lock = true; // ENCLAVAMIENTO POKA-YOKE
        estadoActual = CICLO_COMPLETO;
      }
      break;

    case CICLO_COMPLETO:
      digitalWrite(PIN_LED_OK, HIGH); // Q0.3 ON (Luz Verde)
      // Permanece aquí hasta que el operario retire físicamente el bidón
      if (!inBidon) {
        digitalWrite(PIN_LED_OK, LOW);
        estadoActual = IDLE;
      }
      break;

    case ALARMA_BLOQUEO:
      apagarTodasSalidas();
      digitalWrite(PIN_LED_ALARM, HIGH); // Q0.4 ON (Baliza Roja)
      // Permite volver a IDLE si se restablecen los niveles y el E-Stop
      if (inEStop && inNvlT1 && inNvlT2 && inStop) {
        digitalWrite(PIN_LED_ALARM, LOW);
        estadoActual = IDLE;
      }
      break;
  }

  // 4. TIEMPO DETERMINÍSTICO DE CICLO SCAN (50 ms)
  delay(50);
}

void apagarTodasSalidas() {
  digitalWrite(PIN_EV1_BASE, LOW);
  digitalWrite(PIN_EV2_CONC, LOW);
  digitalWrite(PIN_MOTOR, LOW);
  digitalWrite(PIN_LED_OK, LOW);
  digitalWrite(PIN_LED_ALARM, LOW);
}
